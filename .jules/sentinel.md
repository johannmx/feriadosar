## 2026-04-11 - [Fail Securely on Blocked LocalStorage]

## 2026-04-15 - [Fix NaN Bypass in Numeric Validation]
**Vulnerability:** The numeric validation for the `year` parameter in `src/App.tsx` used `typeof year !== 'number'`. This check is vulnerable to bypasses because in JavaScript, `NaN` and `Infinity` are technically of type `'number'`. If `year` was `NaN`, both `year < 2000` and `year > 2100` would evaluate to `false`, allowing the parameter to bypass the boundary checks completely.
**Learning:** Using `typeof x === 'number'` is insufficient for validating numbers when boundaries are involved, as `NaN` fails numerical comparisons (returning `false`) but passes the type check, which can lead to unexpected behavior or bypasses in validation logic.
**Prevention:** Always use `Number.isSafeInteger()` or `Number.isFinite()` when validating numeric input, especially when ensuring the value falls within specific boundaries, to prevent `NaN` and `Infinity` from bypassing checks.

## 2026-05-01 - [Enforce CORS on External Scripts]

## 2026-05-05 - [Fix Client-Side DoS via Stream Size Limits]
**Vulnerability:** The application attempted to prevent memory exhaustion by checking the `Content-Length` header before parsing API responses. However, if an attacker compromised the external API, they could omit the `Content-Length` header entirely (e.g., using chunked transfer encoding) or spoof it to a small value, bypassing the check and causing `res.json()` to buffer an unbounded payload into client memory, leading to a browser crash.
**Learning:** Validating headers like `Content-Length` is insufficient to prevent memory exhaustion because they are untrusted and optional. The only robust way to limit payload size is to track the actual bytes as they are received.
**Prevention:** Instead of relying on `res.json()` and headers, use the Fetch API's `ReadableStream` (`res.body.getReader()`) to read chunks, accumulate the total length, and explicitly `cancel()` the stream and throw an error if a hard byte limit is exceeded during transmission.
